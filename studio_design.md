# Studio design version 02

Authority: instructor's 2026-11-02 request and supplied Excel workbook structure; confirmed European G-tree and American S-tree convergence distinction. This is one modular studio, retaining the previous version separately.

Learning outcomes: reproduce a claim with stock/financing including dividends; explain the pricing weight; distinguish European parity from American exercise; compute values by backward recursion; interpret the stock distribution; explain refinement and Black–Scholes convergence.

Stable routes: #home, #one, #two, #three, #eight, #convergence, #practice. The introduction explains the core route and extensions. One/two periods show the same inputs, main call/put lattices, formulas, H/B lattices, dollar-allocation lattices, and unrestricted worked calculation tools. Three periods juxtaposes four claims. Eight periods focuses on one claim and its distribution. Each analysis ends with an economic synthesis. Input presets support additional experiments without importing held-out assessment cases.

Ungraded practice permits direct navigation, requested solutions, symbolic arithmetic, and retry. No correctness or writing gates block access. Worked view is the default requested spreadsheet-style output; an optional practice view hides option values. Questions have hints, correct explanations and distractor explanations.

Inputs are at the top. Changes to numerical inputs explicitly require Update analysis; style/type selectors update immediately. Reset restores each page's independent starting inputs. Changed inputs rebuild all model results and clear the selected node. A new expression invalidates its old calculator result. Rate inputs state percentage and compounding conventions.

Colors preserve spreadsheet meaning: dark stock values, red calls, blue puts, green early exercise, distinct amber final exercise, pale yellow inputs. Status text accompanies color. SVG nodes support pointer and keyboard selection; accessible worked tables provide the same numeric detail. Wide lattices scroll within their own containers on narrow screens.

Deployment serves only the public_manifest.json allowlist. Hosting is owner-private; no sharing changes are made. No original XLSM, textbook workspace, instructor manual, homework solution, or QA assets are deployed.
